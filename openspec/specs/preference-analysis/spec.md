# preference-analysis

## Purpose
このスペックは、ユーザーの閲覧履歴から好みの傾向を分析し、タグランキングなどを生成するための要件を定義します。

## Requirements

### Requirement: タグ出現頻度の集計分析
システムは、保存された全ての閲覧履歴からタグ情報を抽出し、各タグの出現回数を集計しなければならない（SHALL）。分析は、作品ごとのタグ重複を考慮しつつ、ユーザーがどのようなカテゴリを好んでいるかを定量化する。

#### Scenario: タグランキングの生成
- **WHEN** ユーザーが傾向分析画面を表示する
- **THEN** 保存された履歴からタグの出現回数が集計され、回数の多い順にランキング表示される

### Requirement: アーティスト・ジャンル別の傾向分析
タグ情報に種別（artist, genre 等）が含まれる場合、システムはそれらを個別に集計し、特定の作者やジャンルへの偏りを分析できなければならない（SHALL）。

#### Scenario: 作者別ランキングの表示
- **WHEN** 分析画面で「作者別」を選択する
- **THEN** `artist` 種別のタグのみを集計したランキングが表示される
