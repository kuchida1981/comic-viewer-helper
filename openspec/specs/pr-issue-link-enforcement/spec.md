# pr-issue-link-enforcement

## Purpose
プルリクエストが関連するイシューに紐付けられていることを自動的に検証し、変更の追跡可能性を確保します。

## Requirements

### Requirement: PRとイシューの紐付けチェック
GitHub Actions は、プルリクエストのタイトルまたは本文にイシュー番号（`#` に続く数字）が含まれているかを検証しなければならない（MUST）。

#### Scenario: イシュー番号が含まれている場合
- **WHEN** PRのタイトルまたは本文に `#123` のような形式が含まれている
- **THEN** ワークフローは成功（Success）として終了する

#### Scenario: イシュー番号が含まれていない場合
- **WHEN** PRのタイトルおよび本文のいずれにも `#数字` の形式が含まれていない
- **THEN** ワークフローはジョブを失敗（Failure）させ、開発者にイシューの紐付けを促す
