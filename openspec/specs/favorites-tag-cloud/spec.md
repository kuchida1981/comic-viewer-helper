# favorites-tag-cloud Specification

## Purpose

お気に入り作品のタグを出現頻度に応じた文字サイズのタグクラウドとして別ビューで表示し、ユーザーの好みの傾向を俯瞰できるようにする。タグクラウドのタグをクリックすることで、そのタグで絞り込んだお気に入り一覧を表示できるようにする。

## Requirements

### Requirement: お気に入りタグをタグクラウドとして表示する
システムは、お気に入り一覧モーダルのお気に入りタブにおいて、一覧ビューとは別にタグクラウドビューを提供しなければならない（SHALL）。タグクラウドビューは、登録されている全お気に入り作品のタグを出現件数で集計し、出現件数の多い上位200件を、件数に応じて段階的に文字サイズを変えて表示しなければならない（SHALL）。

#### Scenario: タグクラウドビューに切り替える
- **WHEN** お気に入りタブでビュー切替の「タグクラウド」を選択する
- **THEN** お気に入り全作品のタグのうち出現件数上位のタグがタグクラウドとして表示され、作品グリッドは表示されない

#### Scenario: 出現件数に応じて文字サイズが変わる
- **WHEN** タグクラウドビューを表示する
- **THEN** 出現件数が多いタグほど大きい(または同じ)文字サイズ段階で表示され、最少件数のタグは最小段階で表示される

#### Scenario: 表示件数が上位200件に制限される
- **WHEN** お気に入りに201種類以上のタグが存在する状態でタグクラウドビューを表示する
- **THEN** 出現件数の多い上位200件のみが表示され、それ以外のタグは表示されない

#### Scenario: タグが200種類以下の場合は全タグが表示される
- **WHEN** お気に入りのタグが200種類以下の状態でタグクラウドビューを表示する
- **THEN** 存在するすべてのタグが表示される

#### Scenario: すべてのタグの件数が同じ場合
- **WHEN** すべてのタグの出現件数が等しい状態でタグクラウドビューを表示する
- **THEN** すべてのタグが同一の文字サイズ段階で表示される

#### Scenario: タグが存在しない場合
- **WHEN** お気に入りが0件、またはタグを持つ作品がない状態でタグクラウドビューを表示する
- **THEN** タグは表示されず、タグが存在しない旨のメッセージが表示される

### Requirement: タグクラウドのタグで絞り込んだお気に入り一覧を表示する
ユーザーは、タグクラウドのタグをクリックして、そのタグで絞り込まれた状態のお気に入り一覧を表示できなければならない（SHALL）。

#### Scenario: タグクラウドのタグをクリックする
- **WHEN** タグクラウドビューでタグをクリックする
- **THEN** 一覧ビューに切り替わり、クリックしたタグが選択状態となって、そのタグを持つお気に入り作品のみがグリッドに表示される

#### Scenario: 既に選択中のタグがある状態でクリックする
- **WHEN** 一覧ビューで既にタグが選択されている状態でタグクラウドビューへ切り替え、別のタグをクリックする
- **THEN** クリックしたタグが選択タグに追加され、すべての選択タグを持つ作品のみが表示される

### Requirement: ビューの切り替えで既存機能を維持する
システムは、タグクラウドビューの追加後も、一覧ビューの既存のトレンドセクション(頻出順表示、ピン留め、選択タグの先頭表示)とタグによる絞り込みを従来どおり提供しなければならない（SHALL）。

#### Scenario: 一覧ビューに戻る
- **WHEN** タグクラウドビューから一覧ビューへ切り替える
- **THEN** 既存のトレンドセクションと作品グリッドが従来どおり表示される

#### Scenario: お気に入りの更新でビューが維持される
- **WHEN** タグクラウドビューを表示中にお気に入りが追加または削除される
- **THEN** タグクラウドが最新のお気に入りで再集計され、表示中のビューは切り替わらない

### Requirement: タグクラウドビューをタグの種類で絞り込む
システムは、お気に入り一覧のタグクラウドビューに、タグの種類（artist、genre など）ごとの絞り込みを提供しなければならない（SHALL）。デフォルトではすべての種類が選択状態（有効）でなければならない（SHALL）。全選択状態で任意の種類を選択した場合、その種類のみが選択状態となり、他の種類は除外されなければならない（SHALL）。1つ以上の種類が除外されている状態で、除外されている種類を選択した場合はその種類も選択状態に追加され、すでに選択されている種類を選択した場合はその種類が除外されなければならない（SHALL）。ただし、選択されている最後の1種類は除外できてはならない（SHALL NOT）。また、選択状態を解除して全選択に戻すリセットボタンを提供し、全選択状態のときは非活性（disabled）としなければならない（SHALL）。種類の切り替えおよびリセットは、タグクラウドビューの表示にのみ作用し、一覧ビューのトレンドセクションおよびお気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: デフォルトではすべての種類が有効
- **WHEN** タグクラウドビューを表示する
- **THEN** お気に入りに存在するすべての種類が有効状態の種類チップとして表示され、全種類のタグがタグクラウドに表示され、リセットボタンは非活性状態で表示される

#### Scenario: 全選択状態で種類をクリックするとその種類のみが選択される
- **WHEN** すべての種類が選択されている状態で種類チップ「genre」をクリックする
- **THEN** `type` が `genre` のタグのみがタグクラウドに表示され、他の種類のチップは薄い無効状態で表示され、リセットボタンが活性状態になる

#### Scenario: 除外された種類をクリックすると選択状態に追加される
- **WHEN** 「genre」のみが選択され「artist」が除外されている状態で、種類チップ「artist」をクリックする
- **THEN** 「genre」と「artist」の両方のタグがタグクラウドに表示され、「artist」のチップが有効状態になる

#### Scenario: 複数選択中に選択済みの種類をクリックするとその種類が除外される
- **WHEN** 「genre」と「artist」が選択され「その他」が除外されている状態で、種類チップ「genre」をクリックする
- **THEN** 「genre」が除外されて「artist」のタグのみがタグクラウドに表示され、「genre」のチップが無効状態になる

#### Scenario: 選択されている最後の1種類はクリックしても除外されない
- **WHEN** 「genre」のみが選択されている状態で、種類チップ「genre」をクリックする
- **THEN** 「genre」は選択状態のまま維持され、タグクラウドの表示は変わらない

#### Scenario: リセットボタンをクリックすると全選択に戻る
- **WHEN** 一部の種類のみが選択されている状態でリセットボタンをクリックする
- **THEN** すべての種類が有効状態に戻り、全種類のタグがタグクラウドに表示され、リセットボタンが再び非活性状態になる

#### Scenario: 無効な種類のチップも表示され続ける
- **WHEN** 絞り込みによって特定の種類が除外され、タグクラウドからその種類のタグが消える
- **THEN** その種類のチップは薄い無効状態で表示され続け、クリックすることで再び選択状態に追加できる

#### Scenario: お気に入りに存在する種類のみチップを表示する
- **WHEN** お気に入りに `artist` と `genre` のタグしか存在しない
- **THEN** 種類チップは「artist」と「genre」のみ表示される

#### Scenario: 種類が1つ以下のときはチップもリセットボタンも表示しない
- **WHEN** お気に入りのタグの種類が1つ以下である
- **THEN** 種類チップおよびリセットボタンは表示されない

#### Scenario: 種類のないタグは「その他」として扱われる
- **WHEN** お気に入りに `type` が `null` のタグが存在する
- **THEN** 「その他」の種類チップが表示され、そのチップの選択で `type` が `null` のタグの絞り込みができる

#### Scenario: 一覧ビューは種類フィルタの影響を受けない
- **WHEN** タグクラウドビューで種類を絞り込んで一覧ビューに切り替える
- **THEN** トレンドセクションとお気に入り作品グリッドの表示は、種類フィルタの影響を受けない

### Requirement: 種類フィルタは上位200件の絞り込み前に適用する
システムは、タグクラウドビューの上位200件の件数制限を、種類フィルタで除外した後のタグに対して適用しなければならない（SHALL）。

#### Scenario: 除外された種類のタグが件数枠を消費しない
- **WHEN** 種類を無効にした結果、残りのタグが200件を超えている
- **THEN** 残ったタグのうち出現件数の多い200件が表示され、除外された種類のタグが件数枠を消費しない

#### Scenario: 除外後に文字サイズの段階は表示中のタグで決まる
- **WHEN** 種類を無効にする
- **THEN** 文字サイズの段階は、表示中のタグの最少件数と最多件数を基準に計算される

### Requirement: 種類フィルタの状態はモーダルを閉じるとリセットする
システムは、種類フィルタの状態を永続化してはならず（SHALL NOT）、お気に入り一覧モーダルを閉じて開き直した場合はすべての種類を有効に戻さなければならない（SHALL）。

#### Scenario: モーダルを開き直すと全種類が有効に戻る
- **WHEN** 種類を無効にした後、モーダルを閉じて再度開く
- **THEN** すべての種類が有効状態で表示される

### Requirement: タグクラウドビューは件数の多いタグを中央に配置する
システムは、タグクラウドビューのタグを、出現件数が多いものほど中央に、少ないものほど外側に配置しなければならない（SHALL）。出現件数が最多のタグを中央に置き、2位を中央の右、3位を中央の左、以降も右・左と交互に外側へ配置しなければならない（SHALL）。出現件数が同じタグは、文字列昇順で順位を決めなければならない（SHALL）。この配置は、タグクラウドビューの表示にのみ作用し、一覧ビューのトレンドセクションおよびお気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: 件数の多いタグが中央に配置される
- **WHEN** 出現件数が A(5)、B(4)、C(3)、D(2)、E(1) のタグが存在する状態でタグクラウドビューを表示する
- **THEN** タグは左から E、C、A、B、D の順（A が中央、B が右隣、C が左隣）で表示される

#### Scenario: 偶数件のタグでも順位に従って配置される
- **WHEN** 出現件数が A(4)、B(3)、C(2)、D(1) のタグが存在する状態でタグクラウドビューを表示する
- **THEN** タグは左から C、A、B、D の順で表示される

#### Scenario: タグが1件のみのときはそのまま表示される
- **WHEN** タグが1件のみ存在する状態でタグクラウドビューを表示する
- **THEN** そのタグが中央に表示される

#### Scenario: 同じ件数のタグは文字列昇順で順位付けされる
- **WHEN** 出現件数が同じタグ b、a、c が存在する状態でタグクラウドビューを表示する
- **THEN** 順位は a、b、c の順となり、a が中央、b が右隣、c が左隣に配置される

#### Scenario: 一覧ビューは配置の影響を受けない
- **WHEN** タグクラウドビューの配置が変わる
- **THEN** 一覧ビューのトレンドセクションとお気に入り作品グリッドの表示は変化しない

### Requirement: 中央配置は上位200件の絞り込みと種類フィルタの後に適用する
システムは、中央配置の並べ替えを、種類フィルタによる除外と上位200件の絞り込みを行った後のタグに対して適用しなければならない（SHALL）。

#### Scenario: 種類フィルタ後のタグが中央配置される
- **WHEN** 種類を無効にしてタグを除外する
- **THEN** 残ったタグが、出現件数の順位に従って中央から外側へ配置される

#### Scenario: 上位200件のみが中央配置される
- **WHEN** タグが201種類以上存在する
- **THEN** 出現件数上位200件が選ばれ、その200件が中央から外側へ配置される
