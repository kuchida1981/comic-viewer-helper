# favorites-tag-cloud Specification

## Purpose

お気に入り作品のタグを出現頻度に応じた文字サイズのタグクラウドとして別ビューで表示し、ユーザーの好みの傾向を俯瞰できるようにする。タグクラウドのタグをクリックすることで、そのタグで絞り込んだお気に入り一覧を表示できるようにする。

## Requirements

### Requirement: お気に入りタグをタグクラウドとして表示する
システムは、お気に入り一覧モーダルのお気に入りタブにおいて、一覧ビューとは別にタグクラウドビューを提供しなければならない（SHALL）。タグクラウドビューは、登録されている全お気に入り作品のタグを出現件数で集計し、出現件数の多い上位200件を、件数に応じて段階的に文字サイズを変えて表示しなければならない（SHALL）。

#### Scenario: タグクラウドビューに切り替える
- **WHEN** お気に入りタブでビュー切替の「タグクラウド」を選択する
- **THEN** お気に入り全作品のタグのうち出現件数上位のタグがタグクラウドとして表示され、作品グリッドは表示されない

#### Scenario: 出現件数に応じて文字サイズが変わる
- **WHEN** タグクラウドビューを表示する
- **THEN** 出現件数が多いタグほど大きい(または同じ)文字サイズ段階で表示され、最少件数のタグは最小段階で表示される

#### Scenario: 表示件数が上位200件に制限される
- **WHEN** お気に入りに201種類以上のタグが存在する状態でタグクラウドビューを表示する
- **THEN** 出現件数の多い上位200件のみが表示され、それ以外のタグは表示されない

#### Scenario: タグが200種類以下の場合は全タグが表示される
- **WHEN** お気に入りのタグが200種類以下の状態でタグクラウドビューを表示する
- **THEN** 存在するすべてのタグが表示される

#### Scenario: すべてのタグの件数が同じ場合
- **WHEN** すべてのタグの出現件数が等しい状態でタグクラウドビューを表示する
- **THEN** すべてのタグが同一の文字サイズ段階で表示される

#### Scenario: タグが存在しない場合
- **WHEN** お気に入りが0件、またはタグを持つ作品がない状態でタグクラウドビューを表示する
- **THEN** タグは表示されず、タグが存在しない旨のメッセージが表示される

### Requirement: タグクラウドのタグで絞り込んだお気に入り一覧を表示する
ユーザーは、タグクラウドのタグをクリックして、そのタグで絞り込まれた状態のお気に入り一覧を表示できなければならない（SHALL）。

#### Scenario: タグクラウドのタグをクリックする
- **WHEN** タグクラウドビューでタグをクリックする
- **THEN** 一覧ビューに切り替わり、クリックしたタグが選択状態となって、そのタグを持つお気に入り作品のみがグリッドに表示される

#### Scenario: 既に選択中のタグがある状態でクリックする
- **WHEN** 一覧ビューで既にタグが選択されている状態でタグクラウドビューへ切り替え、別のタグをクリックする
- **THEN** クリックしたタグが選択タグに追加され、すべての選択タグを持つ作品のみが表示される

### Requirement: ビューの切り替えで既存機能を維持する
システムは、タグクラウドビューの追加後も、一覧ビューの既存のトレンドセクション(頻出順表示、ピン留め、選択タグの先頭表示)とタグによる絞り込みを従来どおり提供しなければならない（SHALL）。

#### Scenario: 一覧ビューに戻る
- **WHEN** タグクラウドビューから一覧ビューへ切り替える
- **THEN** 既存のトレンドセクションと作品グリッドが従来どおり表示される

#### Scenario: お気に入りの更新でビューが維持される
- **WHEN** タグクラウドビューを表示中にお気に入りが追加または削除される
- **THEN** タグクラウドが最新のお気に入りで再集計され、表示中のビューは切り替わらない

### Requirement: タグクラウドビューをタグの種類で絞り込む
システムは、お気に入り一覧のタグクラウドビューに、タグの種類（artist、genre など）ごとの表示切り替えを提供しなければならない（SHALL）。デフォルトではすべての種類が有効でなければならない（SHALL）。種類を無効にした場合、その種類のタグをタグクラウドから除外しなければならない（SHALL）。種類の切り替えは、タグクラウドビューの表示にのみ作用し、一覧ビューのトレンドセクションおよびお気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: デフォルトではすべての種類が有効
- **WHEN** タグクラウドビューを表示する
- **THEN** お気に入りに存在するすべての種類が有効状態の種類チップとして表示され、全種類のタグがタグクラウドに表示される

#### Scenario: 種類を無効にするとその種類のタグが消える
- **WHEN** 種類チップ「genre」をクリックして無効にする
- **THEN** `type` が `genre` のタグがタグクラウドから除外され、他の種類のタグは表示されたままになる

#### Scenario: 無効にした種類を再度有効にすると戻る
- **WHEN** 無効にした種類チップを再度クリックする
- **THEN** その種類のタグがタグクラウドに再び表示される

#### Scenario: 無効な種類のチップも表示され続ける
- **WHEN** 種類を無効にしてタグクラウドからその種類のタグが消える
- **THEN** その種類のチップは薄い無効状態で表示され続け、再度有効にできる

#### Scenario: すべての種類を無効にしてもチップは操作できる
- **WHEN** すべての種類チップを無効にする
- **THEN** タグクラウドにはタグが表示されず、種類チップは表示されたままで再度有効にできる

#### Scenario: お気に入りに存在する種類のみチップを表示する
- **WHEN** お気に入りに `artist` と `genre` のタグしか存在しない
- **THEN** 種類チップは「artist」と「genre」のみ表示される

#### Scenario: 種類が1つ以下のときはチップを表示しない
- **WHEN** お気に入りのタグの種類が1つ以下である
- **THEN** 種類チップは表示されない

#### Scenario: 種類のないタグは「その他」として扱われる
- **WHEN** お気に入りに `type` が `null` のタグが存在する
- **THEN** 「その他」の種類チップが表示され、そのチップの切り替えで `type` が `null` のタグの表示・非表示が切り替わる

#### Scenario: 一覧ビューは種類フィルタの影響を受けない
- **WHEN** タグクラウドビューで種類を無効にして一覧ビューに切り替える
- **THEN** トレンドセクションとお気に入り作品グリッドの表示は、種類フィルタの影響を受けない

### Requirement: 種類フィルタは上位200件の絞り込み前に適用する
システムは、タグクラウドビューの上位200件の件数制限を、種類フィルタで除外した後のタグに対して適用しなければならない（SHALL）。

#### Scenario: 除外された種類のタグが件数枠を消費しない
- **WHEN** 種類を無効にした結果、残りのタグが200件を超えている
- **THEN** 残ったタグのうち出現件数の多い200件が表示され、除外された種類のタグが件数枠を消費しない

#### Scenario: 除外後に文字サイズの段階は表示中のタグで決まる
- **WHEN** 種類を無効にする
- **THEN** 文字サイズの段階は、表示中のタグの最少件数と最多件数を基準に計算される

### Requirement: 種類フィルタの状態はモーダルを閉じるとリセットする
システムは、種類フィルタの状態を永続化してはならず（SHALL NOT）、お気に入り一覧モーダルを閉じて開き直した場合はすべての種類を有効に戻さなければならない（SHALL）。

#### Scenario: モーダルを開き直すと全種類が有効に戻る
- **WHEN** 種類を無効にした後、モーダルを閉じて再度開く
- **THEN** すべての種類が有効状態で表示される
