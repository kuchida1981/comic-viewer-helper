# last-viewed-redirect Specification

## Purpose
ブックマークやURL直打ちなど、サイトの外から作品ページ以外を開いたときに、最後に閲覧した作品へ自動で遷移する機能を提供する。誤爆（サイト内遷移・リロード・戻る/進む）やループを防ぎ、ON/OFF（デフォルトOFF）をユーザーが切り替えられるようにする。
## Requirements
### Requirement: 作品ページ以外を開いたときに最後に閲覧した作品へ遷移する
システムは、機能が有効な状態で作品ページ以外のページが開かれ、閲覧履歴が存在する場合、最後に閲覧した作品の URL へリダイレクトしなければならない（SHALL）。リダイレクトはブラウザの履歴にリダイレクト元を残さない方法（履歴エントリの置換）で行わなければならない（SHALL）。

「最後に閲覧した作品」は、サイト（ホスト）ごとの閲覧履歴のうち最後に閲覧した日時（`lastViewedAt`）が最も新しいものとする。

#### Scenario: 外部から作品ページ以外を開いた
- **WHEN** 機能が有効で、閲覧履歴があり、ブックマークや URL 直打ちなど（リファラなし）でサイトのトップページを開いた
- **THEN** システムは最後に閲覧した作品の URL へ遷移する
- **AND** リダイレクト元のページはブラウザの履歴に残らない

#### Scenario: 別サイトのリンクから作品ページ以外を開いた
- **WHEN** 機能が有効で、閲覧履歴があり、別オリジンのページのリンクからサイトの作品ページ以外を開いた
- **THEN** システムは最後に閲覧した作品の URL へ遷移する

#### Scenario: 遷移先で前回のページ位置へ戻れる
- **WHEN** リダイレクト先の作品ページに保存済みの読書位置（1ページ目以外）がある
- **THEN** 既存の再開通知が表示される
- **AND** ページ位置は自動では移動されない

### Requirement: リダイレクトが発動しない条件
システムは、次のいずれかに該当する場合はリダイレクトを行ってはならない（SHALL NOT）。

- 機能が無効である
- 現在のページが作品ページである
- 遷移元が同一オリジンのページである（サイト内の通常遷移）
- ページの読み込み種別がリロード、またはブラウザの戻る/進むである
- 閲覧履歴が空である
- 遷移先の URL が現在のページの URL と同じである
- 遷移先の URL が作品ページと判定されない

#### Scenario: サイト内の通常遷移では遷移しない
- **WHEN** ユーザーが作品ページから検索結果ページやタグページのリンクをクリックして遷移した
- **THEN** システムはリダイレクトを行わず、遷移先のページがそのまま表示される

#### Scenario: 作品ページでは遷移しない
- **WHEN** 作品ページが開かれた
- **THEN** システムはリダイレクトを行わない

#### Scenario: 履歴が空の場合は何もしない
- **WHEN** 機能が有効で、閲覧履歴が空の状態で作品ページ以外を外部から開いた
- **THEN** システムはリダイレクトを行わず、ページがそのまま表示される

#### Scenario: リロード・戻る/進むでは遷移しない
- **WHEN** 作品ページ以外のページをリロードした、またはブラウザの戻る/進むでそのページに到達した
- **THEN** システムはリダイレクトを行わない

#### Scenario: 遷移先が作品ページでない場合は遷移しない
- **WHEN** 閲覧履歴の最新エントリが、現在のアダプターで作品ページと判定されない URL である
- **THEN** システムはリダイレクトを行わない
- **AND** リダイレクトのループは発生しない

### Requirement: リダイレクトの ON/OFF 設定
システムは、リダイレクト機能を有効/無効にする設定を提供しなければならない（SHALL）。デフォルトは無効（OFF）とし、設定値はユーザースクリプト専用ストレージに永続化されなければならない（SHALL）。

#### Scenario: デフォルトは無効
- **WHEN** 設定が一度も変更されていない状態で作品ページ以外を外部から開いた
- **THEN** システムはリダイレクトを行わない

#### Scenario: 設定の変更と永続化
- **WHEN** ユーザーが設定画面でリダイレクトを有効にした
- **THEN** 設定値が永続化され、以降のページ読み込みでも有効のまま保持される

#### Scenario: 作品ページ以外ではスクリプトの他機能を初期化しない
- **WHEN** 作品ページ以外のページが開かれた
- **THEN** システムは作品ページ向けの機能（画像フィット、ナビゲーション、UI の表示等）を初期化せず、リダイレクトの判定のみを行う
