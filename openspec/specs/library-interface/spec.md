# library-interface

## Purpose
お気に入りと閲覧履歴を統合したライブラリUIを提供し、ユーザーが過去の閲覧作品を効率的に管理・再訪問できるようにするための機能を定義します。

## Requirements

### Requirement: 統合ライブラリUI
システムは「お気に入り」と「閲覧履歴」を1つのモーダル（ライブラリ）として表示しなければならない（SHALL）。

#### Scenario: ライブラリモーダルを開く
- **WHEN** 「お気に入り一覧」メニューまたはショートカットキーを実行する
- **THEN** お気に入りと履歴を切り替えるタブを備えたライブラリモーダルが表示される

### Requirement: タブによる表示切り替え
ユーザーはライブラリモーダル内で「お気に入り」と「履歴」の表示を切り替えられなければならない（SHALL）。

#### Scenario: 履歴タブに切り替える
- **WHEN** ライブラリモーダルの「履歴」タブをクリックする
- **THEN** 表示内容が閲覧履歴のグリッドに切り替わる

### Requirement: 表示順のソート機能
ユーザーはライブラリ内の表示順を特定の基準で並び替えられなければならない（SHALL）。

#### Scenario: 閲覧回数順にソートする
- **WHEN** 履歴タブにおいて「閲覧回数順」を選択する
- **THEN** 閲覧回数の多い順（降順）に作品が並び替えられる

### Requirement: 履歴からのクイックアクション
ライブラリ一覧に表示される各作品について、お気に入りへの登録/解除、およびリストからの削除を容易に行えなければならない（SHALL）。

#### Scenario: 履歴からお気に入りに追加する
- **WHEN** 履歴タブの一覧で、ある作品の「♥（お気に入り）」ボタンをクリックする
- **THEN** その作品がお気に入りリストに追加され、アイコンが塗りつぶし状態に変わる

#### Scenario: 履歴から項目を削除する
- **WHEN** 履歴タブの一覧で、ある作品の「×（削除）」ボタンをクリックする
- **THEN** その作品が履歴から削除される
