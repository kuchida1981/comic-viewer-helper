# tag-pinning Specification

## Purpose
お気に入り一覧のタグトレンドセクションにおいて、ユーザーが特定のタグを「ピン留め」できる機能を提供する。ピン留めされたタグは出現回数に関わらず常にリストの先頭に表示され、ホストごとに永続化される。

## Requirements

### Requirement: タグをピン留めする
ユーザーは、お気に入り一覧のタグトレンドセクションにおいて、特定のタグを「ピン留め」できなければならない（SHALL）。

#### Scenario: タグのピンボタンをクリックしてピン留めする
- **WHEN** タグチップ内のピンアイコンをクリックする
- **THEN** そのタグが `Store` の `pinnedTags` リストに追加され、ピンアイコンがアクティブ状態（塗りつぶし）になる

### Requirement: タグのピン留めを解除する
ユーザーは、ピン留めされたタグのピンを解除できなければならない（SHALL）。

#### Scenario: アクティブなピンアイコンをクリックしてピンを解除する
- **WHEN** ピン留めされているタグチップ内のアクティブなピンアイコンをクリックする
- **THEN** そのタグが `Store` の `pinnedTags` リストから削除され、ピンアイコンが非アクティブ状態になる
