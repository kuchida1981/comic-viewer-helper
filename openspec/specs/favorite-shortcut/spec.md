# favorite-shortcut

## Purpose
キーボード操作によるお気に入りの追加・解除機能を提供し、ユーザーのアクセシビリティと利便性を向上させます。

## Requirements

### Requirement: キーボードショートカットによるお気に入り登録の切り替え
ユーザーはキーボードの特定のキーを押すことで、現在閲覧中の作品のお気に入り状態をトグルできなければならない（SHALL）。

#### Scenario: ショートカットキーでトグルする
- **WHEN** ビューアが有効で、入力フィールドにフォーカスがない状態で 'v' キーを押す
- **THEN** お気に入り状態が反転し、ナビゲーションボタンのアイコンが更新される
