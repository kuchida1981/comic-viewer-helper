## ADDED Requirements

### Requirement: トレンドセクションのUI統合
システムは、作品リストの表示を伴うあらゆるUI（検索、履歴、関連作品）において、作品群のタグを集計して表示する「トレンドセクション」を提供しなければならない（SHALL）。

#### Scenario: 検索結果におけるトレンド表示
- **WHEN** 検索結果が表示されたとき
- **THEN** リストの上部に検索結果に含まれる作品のタグ集計が表示される

#### Scenario: 閲覧履歴におけるトレンド表示
- **WHEN** 閲覧履歴タブが表示されたとき
- **THEN** リストの上部に閲覧履歴に含まれる作品のタグ集計が表示される

#### Scenario: 関連作品におけるトレンド表示
- **WHEN** 関連作品リストが表示されたとき
- **THEN** リストの上部に関連作品に含まれる作品のタグ集計が表示される

#### Scenario: タグによるリストの絞り込み
- **WHEN** トレンドセクション内のタグチップをクリックしたとき
- **THEN** 表示されている作品リストの内容が、そのタグを持つ作品のみに絞り込まれなければならない
