## ADDED Requirements

### Requirement: バックグラウンドでのタグ順次フェッチ
システムは、表示中の作品リスト内にタグ情報が未取得（キャッシュにない）作品がある場合、それらの作品ページをバックグラウンドで順次フェッチし、タグ情報を取得しなければならない（SHALL）。

#### Scenario: 未取得作品のフェッチ開始
- **WHEN** 検索結果、閲覧履歴、または関連作品のリストが表示され、タグが未取得の作品が含まれるとき
- **THEN** システムは未取得作品のページを順次フェッチしてタグを取得する

#### Scenario: フェッチ時のレート制限
- **WHEN** 連続して複数の作品ページをフェッチするとき
- **THEN** システムはサーバー負荷を軽減するため、各リクエストの間に一定のディレイ（500ms以上）を設けなければならない

#### Scenario: 取得結果の即時反映
- **WHEN** 一つの作品のタグ情報の取得が完了したとき
- **THEN** システムは直ちにそのタグ情報をStoreおよびUI（トレンド集計）に反映させなければならない
