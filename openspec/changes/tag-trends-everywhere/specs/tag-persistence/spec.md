## ADDED Requirements

### Requirement: 作品タグ情報の永続キャッシュ
システムは、取得した作品のタグ情報を作品URLをキーとして永続ストレージ（GM_storage）に保存し、次回起動時にも利用可能にしなければならない（SHALL）。

#### Scenario: キャッシュの保存
- **WHEN** 作品のメタデータ（タグを含む）が正常に取得されたとき
- **THEN** システムはそのタグ情報を永続ストレージに保存する

#### Scenario: キャッシュの利用
- **WHEN** 作品リストが表示され、ある作品のURLがキャッシュに存在するとき
- **THEN** システムはネットワークリクエストを行わずにキャッシュからタグ情報を取得して表示に利用する
