## ADDED Requirements

### Requirement: ランダムジャンプ機能
システムは、現在の作品の関連作品やサイト内の検索結果、およびユーザーのお気に入り作品の中からランダムに一つを選択して遷移する機能を提供しなければならない（SHALL）。

#### Scenario: ランダムジャンプの実行（お気に入り優先）
- **WHEN** 「おすすめ（ランダム）」ボタン（またはショートカット）が操作される
- **THEN** システムは、お気に入り作品、関連作品、検索キャッシュを遷移候補としてリストアップする
- **AND** お気に入り登録されている作品には、未登録の作品よりも高い重み（10倍程度）を付けてランダムに1件選択する
- **AND** 選択された作品の URL へ遷移を試みる

### Requirement: お気に入り作品が存在しない場合のランダムジャンプ
お気に入り作品が一つも登録されていない場合でも、システムは他の候補（関連作品、検索キャッシュ）からランダムジャンプを実行できなければならない（SHALL）。

#### Scenario: お気に入りなしでのランダムジャンプ
- **WHEN** お気に入り作品が 0 件の状態で「おすすめ（ランダム）」ボタンが操作される
- **THEN** システムは、関連作品と検索キャッシュのみを候補として、一様な確率でランダムに1件選択し遷移する
