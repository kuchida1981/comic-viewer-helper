## ADDED Requirements

### Requirement: タグクラウドは順位の高いタグを中央に配置する
システムは、タグクラウドのタグを、順位（選択中、ピン留め、件数降順の優先順）が高いものほど中央に、低いものほど外側に配置しなければならない（SHALL）。順位1位のタグを中央に置き、2位を中央の右、3位を中央の左、以降も右・左と交互に外側へ配置しなければならない（SHALL）。この配置は、タグクラウドの表示にのみ作用し、お気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: 件数の多いタグが中央に配置される
- **WHEN** 件数が A(5)、B(4)、C(3)、D(2)、E(1) のタグがあり、お気に入り一覧モーダルを開く
- **THEN** タグクラウドは左から E、C、A、B、D の順（A が中央、B が右隣、C が左隣）で表示される

#### Scenario: タグが1件のみのときはそのまま表示される
- **WHEN** タグが1件のみ存在する
- **THEN** そのタグが中央に表示される

#### Scenario: 選択中・ピン留めのタグは中央付近に配置される
- **WHEN** 件数の少ないタグをピン留めする、または選択する
- **THEN** そのタグは件数にかかわらず、選択中、ピン留め、件数降順の順位に従って中央付近に配置される

#### Scenario: 作品グリッドは配置の影響を受けない
- **WHEN** タグクラウドの配置が変わる
- **THEN** お気に入り作品グリッドに表示される作品の内容と順序は変化しない

### Requirement: 表示件数制限は中央配置前の順位に基づく
システムは、「上位10件 / すべて表示」の件数制限を、中央配置に並べ替える前の順位に基づいて適用しなければならない（SHALL）。

#### Scenario: 上位10件のみが中央配置される
- **WHEN** タグが10件を超えており、上位10件表示になっている
- **THEN** 順位の高い10件が選ばれ、その10件が中央から外側へ配置される

#### Scenario: すべて表示に切り替えても順位に基づいて配置される
- **WHEN** 「すべて表示」に切り替える
- **THEN** すべてのタグが、順位に基づいて中央から外側へ配置される
