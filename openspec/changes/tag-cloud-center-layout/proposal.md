# Proposal

## Why

タグクラウド（お気に入り一覧のトレンドセクション）は、順位の高いタグから左上へ順に並ぶため、件数の多いタグが視覚的にまとまらず、傾向をつかみにくい。件数の多いタグを中央に、少ないタグほど外側に配置し、好みの傾向をひと目で把握できるようにしたい（Issue #280）。

## What Changes

- タグクラウドを、順位1位を中央、2位を右、3位を左…と交互に外側へ配置する横一列の中央寄せ（ピラミッド型）にする。
- 順位は従来どおり「選択中 → ピン留め → 件数降順」で決め、その順位を中央から外側へ割り当てる。
- 「上位10件 / すべて表示」の切り替えは、従来と同じ順位に基づいて動作する。
- お気に入り作品グリッドの表示は変更しない。
- 配置の並べ替えは `logic.ts` の純関数として実装する。
- 円形・放射状の配置や、件数に応じたフォントサイズの変化はスコープ外とする。

## Capabilities

### New Capabilities
なし。

### Modified Capabilities
- `favorite-tag-trends`: タグクラウドの配置を「順位の高いタグが中央」とする要件を追加する。

## Impact

- `src/logic.ts`: 順位順の配列を中央から外側へ並べ替える純関数を追加する。100% カバレッジを維持する。
- `src/ui/components/FavoritesModal.ts`: 描画前に並べ替えを適用する。
- `src/ui/styles.ts`: タグ領域を `justify-content: center` にする。
- 関連テスト（`logic.test.ts`、`FavoritesModal.test.ts`）を追加する。
- `calculateTrends` の戻り値・順位付け、保存形式、`Store` は変更しない。
