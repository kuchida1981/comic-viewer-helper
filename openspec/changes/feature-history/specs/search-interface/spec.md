## MODIFIED Requirements

### Requirement: 検索キーワード入力インターフェース
システムは、ユーザーが検索キーワードを入力し、検索を実行するためのモーダル形式のインターフェースを提供しなければならない (SHALL)。このインターフェースは、通信中の状態を適切にフィードバックし、背面のビューアーとのインタラクションを完全に分離しなければならない。また、過去の検索履歴を提示し、素早い再検索を支援しなければならない。また、特定のタグやジャンルによるフィルタリング検索時には、その条件が明確に示されなければならない。**さらに、タブ切り替えによって「検索」「閲覧履歴」「傾向分析」の各モードを統合的に利用できなければならない。**

#### Scenario: 検索モーダルの表示（タブ統合）
- **WHEN** ツールバーの検索アイコンをクリックした時、またはキーボードの `/` キーを押下した時
- **THEN** 検索モーダルが表示され、デフォルトで「検索」タブが選択されていること
- **AND** モーダル上部に「検索」「履歴」「分析」を切り替えるためのタブUIが表示されること

#### Scenario: 履歴タブへの切り替え
- **WHEN** 検索モーダル内で「履歴」タブをクリックする
- **THEN** 閲覧履歴リストが表示され、最近見た作品を確認できること

#### Scenario: 分析タブへの切り替え
- **WHEN** 検索モーダル内で「分析」タブをクリックする
- **THEN** 好みの傾向（タグランキング）が表示されること
