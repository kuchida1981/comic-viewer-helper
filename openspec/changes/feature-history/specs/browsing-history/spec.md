## ADDED Requirements

### Requirement: 閲覧履歴の自動記録
システムは、作品ページが読み込まれた際、その作品のタイトル、URL、サムネイル、タグ情報、および閲覧日時を自動的に永続ストレージ（IndexedDB）に記録しなければならない（SHALL）。同一作品を複数回閲覧した場合、既存のレコードを最新の閲覧日時で更新するか、新規に履歴を追加しなければならない。

#### Scenario: 作品閲覧時の履歴保存
- **WHEN** 作品ページが正常に読み込まれ、メタデータが取得される
- **THEN** IndexedDB の `history` ストアに当該作品の情報が保存される

### Requirement: 履歴データの取得と表示
システムは、保存された閲覧履歴を時系列（降順）で取得し、UIにリスト表示する機能を提供しなければならない（SHALL）。

#### Scenario: 履歴リストの表示
- **WHEN** ユーザーが履歴画面を開く
- **THEN** IndexedDB から最新の閲覧履歴が取得され、作品タイトルやサムネイルと共に一覧表示される

### Requirement: 履歴データの削除
システムは、特定の履歴レコードまたは全履歴を一括で削除する機能を提供しなければならない（SHALL）。

#### Scenario: 特定作品の履歴削除
- **WHEN** ユーザーが履歴リスト内の特定の作品に対して削除操作を行う
- **THEN** 当該作品のレコードが IndexedDB から削除され、UIが更新される
