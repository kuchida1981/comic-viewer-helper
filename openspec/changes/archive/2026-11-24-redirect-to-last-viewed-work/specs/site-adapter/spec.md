## ADDED Requirements

### Requirement: 作品ページの判定
サイトアダプターは、URL を受け取り、その URL が作品ページ（画像を閲覧するページ）かどうかを判定して返さなければならない（SHALL）。判定のルール（パス構造など）はサイトごとの差異としてアダプターが定義し、アダプターの利用側は特定のパス構造を前提としてはならない（SHALL NOT）。判定は DOM に依存せず、URL のみに基づかなければならない（SHALL）。

#### Scenario: 作品ページの URL
- **WHEN** デフォルトアダプターが `/magazine/` または `/fanzine/` 配下の URL（例: `https://example.com/magazine/123`）で判定を求められた
- **THEN** 作品ページであると判定される

#### Scenario: 作品ページ以外の URL
- **WHEN** デフォルトアダプターがトップページ、検索結果ページ、その他 `/magazine/`・`/fanzine/` 配下でないパスの URL で判定を求められた
- **THEN** 作品ページではないと判定される

#### Scenario: クエリパラメータ・ハッシュの影響を受けない
- **WHEN** 作品ページの URL にクエリパラメータやハッシュが付与されている
- **THEN** 付与されていない場合と同じ判定結果になる

#### Scenario: DOM 構築前の判定
- **WHEN** ドキュメントの読み込みが始まった直後（DOM が未構築）に判定を求められた
- **THEN** URL のみで判定結果を返せる
