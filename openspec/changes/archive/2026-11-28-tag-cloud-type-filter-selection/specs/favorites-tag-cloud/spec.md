## MODIFIED Requirements

### Requirement: タグクラウドビューをタグの種類で絞り込む
システムは、お気に入り一覧のタグクラウドビューに、タグの種類（artist、genre など）ごとの絞り込みを提供しなければならない（SHALL）。デフォルトではすべての種類が選択状態（有効）でなければならない（SHALL）。全選択状態で任意の種類を選択した場合、その種類のみが選択状態となり、他の種類は除外されなければならない（SHALL）。1つ以上の種類が除外されている状態で、除外されている種類を選択した場合はその種類も選択状態に追加され、すでに選択されている種類を選択した場合はその種類が除外されなければならない（SHALL）。ただし、選択されている最後の1種類は除外できてはならない（SHALL NOT）。また、選択状態を解除して全選択に戻すリセットボタンを提供し、全選択状態のときは非活性（disabled）としなければならない（SHALL）。種類の切り替えおよびリセットは、タグクラウドビューの表示にのみ作用し、一覧ビューのトレンドセクションおよびお気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: デフォルトではすべての種類が有効
- **WHEN** タグクラウドビューを表示する
- **THEN** お気に入りに存在するすべての種類が有効状態の種類チップとして表示され、全種類のタグがタグクラウドに表示され、リセットボタンは非活性状態で表示される

#### Scenario: 全選択状態で種類をクリックするとその種類のみが選択される
- **WHEN** すべての種類が選択されている状態で種類チップ「genre」をクリックする
- **THEN** `type` が `genre` のタグのみがタグクラウドに表示され、他の種類のチップは薄い無効状態で表示され、リセットボタンが活性状態になる

#### Scenario: 除外された種類をクリックすると選択状態に追加される
- **WHEN** 「genre」のみが選択され「artist」が除外されている状態で、種類チップ「artist」をクリックする
- **THEN** 「genre」と「artist」の両方のタグがタグクラウドに表示され、「artist」のチップが有効状態になる

#### Scenario: 複数選択中に選択済みの種類をクリックするとその種類が除外される
- **WHEN** 「genre」と「artist」が選択され「その他」が除外されている状態で、種類チップ「genre」をクリックする
- **THEN** 「genre」が除外されて「artist」のタグのみがタグクラウドに表示され、「genre」のチップが無効状態になる

#### Scenario: 選択されている最後の1種類はクリックしても除外されない
- **WHEN** 「genre」のみが選択されている状態で、種類チップ「genre」をクリックする
- **THEN** 「genre」は選択状態のまま維持され、タグクラウドの表示は変わらない

#### Scenario: リセットボタンをクリックすると全選択に戻る
- **WHEN** 一部の種類のみが選択されている状態でリセットボタンをクリックする
- **THEN** すべての種類が有効状態に戻り、全種類のタグがタグクラウドに表示され、リセットボタンが再び非活性状態になる

#### Scenario: 無効な種類のチップも表示され続ける
- **WHEN** 絞り込みによって特定の種類が除外され、タグクラウドからその種類のタグが消える
- **THEN** その種類のチップは薄い無効状態で表示され続け、クリックすることで再び選択状態に追加できる

#### Scenario: お気に入りに存在する種類のみチップを表示する
- **WHEN** お気に入りに `artist` と `genre` のタグしか存在しない
- **THEN** 種類チップは「artist」と「genre」のみ表示される

#### Scenario: 種類が1つ以下のときはチップもリセットボタンも表示しない
- **WHEN** お気に入りのタグの種類が1つ以下である
- **THEN** 種類チップおよびリセットボタンは表示されない

#### Scenario: 種類のないタグは「その他」として扱われる
- **WHEN** お気に入りに `type` が `null` のタグが存在する
- **THEN** 「その他」の種類チップが表示され、そのチップの選択で `type` が `null` のタグの絞り込みができる

#### Scenario: 一覧ビューは種類フィルタの影響を受けない
- **WHEN** タグクラウドビューで種類を絞り込んで一覧ビューに切り替える
- **THEN** トレンドセクションとお気に入り作品グリッドの表示は、種類フィルタの影響を受けない
