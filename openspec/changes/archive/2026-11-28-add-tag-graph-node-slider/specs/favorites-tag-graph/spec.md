# Spec Delta

## MODIFIED Requirements

### Requirement: タグをノードとして表示する
システムは、お気に入りのタグのうち出現件数上位のタグ（同数は文字列昇順）を、ユーザーが設定した表示ノード数まで、ノードとして表示しなければならない（SHALL）。ノードはタグ名のラベルを持ち、件数が多いほど大きく、タグの種類ごとの色で表示されなければならない（SHALL）。

#### Scenario: ノード数が制限される
- **WHEN** 表示ノード数が50で、51種類以上のタグが存在する
- **THEN** 出現件数上位の50件だけがノードになる

#### Scenario: 件数と種類が見た目に反映される
- **WHEN** 件数と種類の異なるタグを表示する
- **THEN** 件数の多いノードは少ないノード以上の大きさになり、種類の異なるノードは異なる色になる

## ADDED Requirements

### Requirement: 表示ノード数をスライダーで調整できる
システムは、グラフビューに表示ノード数のスライダーと現在の値を表示しなければならない（SHALL）。値は10から100まで10刻みで、初期値は50でなければならない（SHALL）。操作中の値は、ただちにグラフへ反映しなければならない（SHALL）。

#### Scenario: スライダーを動かす
- **WHEN** 51種類以上のタグがある状態で、スライダーを30にする
- **THEN** ボタンを離す前でも、上位30件のノードと現在の値30が表示される

#### Scenario: タグの種類数が設定値より少ない
- **WHEN** タグが20種類で、表示ノード数が50である
- **THEN** 20件すべてがノードになる

#### Scenario: スライダーを操作した後にモーダルを閉じる
- **WHEN** スライダーにフォーカスがある状態で `Esc` キーを押す
- **THEN** モーダルが閉じる

### Requirement: 表示ノード数を端末に保存する
システムは、選ばれた表示ノード数を端末に保存し、次にグラフを表示するときに使わなければならない（SHALL）。この値は Gist 同期の対象にしてはならない（SHALL NOT）。

#### Scenario: モーダルを開き直す
- **WHEN** 表示ノード数を80にした後、モーダルを閉じて開き直す
- **THEN** スライダーは80で、上位80件が表示される

#### Scenario: 保存された値が不正
- **WHEN** 保存された値が数値でない、または範囲や刻みに合わない
- **THEN** 数値でなければ50を使い、数値なら範囲内の最も近い刻みの値を使う

### Requirement: ノード数を変えても配置を引き継ぐ
システムは、表示ノード数を変えたとき、残るノードを直前の位置から動かし、ズームと表示位置を保たなければならない（SHALL）。増えるノードのうち、表示中のノードと線でつながるものは、その近くから動き始めなければならない（SHALL）。

#### Scenario: ノード数を増やす
- **WHEN** 表示ノード数を30から40にする
- **THEN** 元の30件は直前の位置から動き、つながりのある追加ノードは相手の近くに現れる

### Requirement: ノード数が多くても表示領域に収める
システムは、表示ノード数が10から100のいずれでも、初期のズームと表示位置で、配置が落ち着いた後のノードが表示領域に収まるようにしなければならない（SHALL）。

#### Scenario: 100ノードを表示する
- **WHEN** 表示ノード数を100にして、101種類以上のタグを表示する
- **THEN** 落ち着いた後、すべてのノードが表示領域内にある
