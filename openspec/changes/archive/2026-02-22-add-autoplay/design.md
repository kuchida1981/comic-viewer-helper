## Context

現在のコミックビューアには、手動によるページ送りと、作品情報（info 画面）への自動遷移、ジャンプ機能などが実装されています。ユーザーが読書中、一定の間隔で自動的にページをめくりたいという要望に応えるため、オートプレイ機能を導入します。

## Goals / Non-Goals

**Goals:**
- 一定の間隔（デフォルト5秒、1〜99秒の範囲で設定可能）で自動的に次のページへ遷移する。
- ユーザーの手動操作（キー入力、クリック、ジャンプ、設定変更等）に干渉せず、操作があった場合はオートプレイタイマーをリセットし、自然な読書体験を維持する。
- オートプレイの状態（ON/OFF、秒数）を永続化する。
- 最終ページ到達時には適切に停止する。

**Non-Goals:**
- アニメーションの速度設定（スクロール自体の速度は現状の `smooth` のまま）。
- 複数ページを一度に飛ばすオートプレイ。

## Decisions

### 1. タイマーの管理場所
- **Decision:** `Navigator` クラスでタイマー（`NodeJS.Timeout` / `number`）を管理する。
- **Rationale:** ナビゲーションのライフサイクル（実行中フラグ、スクロール完了待ち等）に最も近いため、タイマーのリセットや停止を統合的に制御しやすい。
- **Alternatives:** `UIManager` で管理する案もあったが、スクロール完了後にタイマーを再開するなどの細かい制御が難しくなるため見送った。

### 2. タイマーのリセット方式
- **Decision:** `Navigator` の各パブリックメソッド（`scrollToImage`, `jumpToPage`, `scrollToEdge`）の呼び出し時に、共通の `_resetAutoplayTimer()` を実行する。
- **Rationale:** すべての手動ナビゲーション操作を確実に捕捉し、オートページ送りと手動操作が重ならないようにするため。

### 3. UI の配置
- **Decision:** `SpreadControls` の右側、またはGUIパネルの末尾に `AutoplayControls` を新規作成して配置する。
- **Rationale:** 設定項目（チェックボックスと秒数入力）は既存の GUI パネルの構造と親和性が高いため。

### 4. 最終ページ到達時の挙動
- **Decision:** `isAutoplayEnabled` を `false` に変更する。
- **Rationale:** info 画面（メタデータモーダル）が表示された後、自動的に次のページへ進む先がないため、明示的に OFF にするのがユーザーにとっても直感的である。

## Risks / Trade-offs

- **[Risk]** タイマーがリセットされずにページが勝手にめくられてしまう。
  - **Mitigation:** `Navigator` の全ナビゲーションメソッドにリセット処理を挟む。また、スクロール完了（`pendingTargetIndex` のクリア）を待ってからタイマーを再開する仕組みを導入する。
- **[Risk]** 数値入力中にオートプレイが発火してフォーカスが外れる。
  - **Mitigation:** 数値入力フィールド（`input[type="number"]`）にフォーカスがある間は、ショートカットキー同様にナビゲーション操作を抑制する。

## 永続化設計

`Store` の `STORAGE_KEYS` に以下を追加する：
- `AUTOPLAY_ENABLED`: `'true'` | `'false'` (boolean として扱う)
- `AUTOPLAY_INTERVAL`: `'1'`〜`'99'` (number として扱う)
