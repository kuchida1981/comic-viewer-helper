## Why

現在、本スクリプトのデータ（閲覧履歴、お気に入り、設定など）は `GM_setValue` を通じて各ブラウザのローカルストレージに保存されています。そのため、複数の端末やブラウザ（例：PCとモバイル、あるいは自宅と職場のPC）で閲覧する際、データが同期されず、履歴の継続や設定の再適用を手動で行う必要があります。

この変更により、GitHub Gist を介した自動同期機能を導入し、ユーザーがどこでも同じ環境で漫画を閲覧できるようにします。

## What Changes

- **GitHub Gist 同期プロバイダーの導入**: `GM_xmlhttpRequest` を使用して GitHub Gist API と通信し、データをアップロード・ダウンロードする機能を実装します。
- **自動同期メカニズム**:
    - `Store` のデータ変更時に一定のディレイをおいて自動的にアップロード（Push）します。
    - スクリプト起動時、および必要に応じて手動でデータを取得（Pull）します。
- **同期設定 UI の追加**:
    - GitHub Personal Access Token (PAT) および Gist ID を入力・管理するための設定画面を追加します。
    - 同期を有効にするかどうかを選択できるオプトイン方式とします。
- **状態管理の拡張**: クラウドから取得したデータをローカルの状態にマージまたは上書きする処理を `Store` に統合します。

## Capabilities

### New Capabilities
- `sync-data-via-gist`: GitHub Gist API を使用したデータの永続化と、端末間での同期制御機能。

### Modified Capabilities
- `state-management`: ローカルの変更を同期キューに送る、およびリモートからの更新をローカル状態に反映させるための要件を追加。

## Impact

- **`src/store.ts`**: 同期処理のトリガー（フック）の追加、およびリモートデータの統合処理。
- **`src/managers/`**: 新しい `SyncManager` クラスの作成。
- **`src/ui/`**: 同期設定（PAT, Gist ID等）を表示・編集するための UI コンポーネントの追加または拡張。
- **`src/header.ts`**: `GM_xmlhttpRequest` などのクロスドメイン通信に必要な `@grant` の追加。
