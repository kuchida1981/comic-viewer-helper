## MODIFIED Requirements

### Requirement: Centralized Shortcut Management
システムは、すべてのキーボードショートカットの定義（ID、キー、修飾キー）を一元管理しなければならない（SHALL）。表示用のラベルや説明文は、ID を基に多言語対応辞書から取得されるものとし、ヘルプモーダルとイベントハンドラの双方が同一のデータソースを参照することを保証する。
また、ショートカットの判定においては、修飾キー（Shift 等）を必要とするショートカット（例: `Shift+Space`）と、同一のキー値を持ちつつ修飾キーを必要としないショートカット（例: `Space`）を厳密に区別して判定しなければならない（SHALL）。ただし、`?` のように Shift を押すことで文字自体が変化するキーについては、Shift キーの状態に関わらず文字（`e.key`）が一致すればマッチするものとする。

#### Scenario: IDベースのショートカット管理
- **WHEN** 開発者が一元管理されているデータ構造に新しいショートカットを ID（例: `nextPage`）と共に追加する
- **THEN** システムは現在の言語設定に応じた適切なラベルと説明文を辞書から取得し、ヘルプモーダルに表示する
- **AND** キーボードイベントハンドラは、ラベル名ではなく ID に基づいて動作を決定する

#### Scenario: Space と Shift+Space の区別
- **WHEN** ユーザーが `Space` キーを（Shift なしで）押下する
- **THEN** `nextPage` ショートカット（`Space` を含む）にマッチする
- **WHEN** ユーザーが `Shift + Space` キーを押下する
- **THEN** `prevPage` ショートカット（`Shift+Space` を含む）にマッチし、`nextPage` にはマッチしない
