## MODIFIED Requirements

### Requirement: Help Content Display
ヘルプモーダルは、利用可能なすべてのキーボードショートカットとその説明、同期設定、およびアプリケーション의 バージョン情報を、現在の言語設定に応じた翻訳テキストで一覧形式で表示しなければならない（SHALL）。各セクションは論理的な順序（ショートカット -> 設定 -> バージョン情報）で配置され、視覚的に区別可能でなければならない（SHALL）。

#### Scenario: View help content in logical order
- **WHEN** ヘルプモーダルが表示されている
- **THEN** 最上部にキーボードショートカット一覧が表示される
- **AND** その下に同期設定セクションが表示される
- **AND** 最下部にバージョン情報が表示される

#### Scenario: View shortcut list
- **WHEN** ヘルプモーダルが表示されている
- **THEN** ユーザーは `j/k` (ナビゲーション), `a` (オートプレイ), `d` (見開きトグル), `o` (オフセット), `i` (情報), `f` (フルスクリーン), `/` (検索), `?` (ヘルプ) などの操作説明を確認できる

#### Scenario: 翻訳されたショートカット一覧の表示
- **WHEN** 日本語環境でヘルプモーダルが表示されている
- **THEN** ユーザーは「次のページへ移動」や「オートプレイのON/OFF」、「見開きモードのON/OFF」や「検索の開始」といった日本語の説明を確認できる
- **AND** 英語環境では、これらが英語（"Move to next page", "Toggle Autoplay", "Toggle Fullscreen", "Start search" 等）で表示される

#### Scenario: ショートカット一覧の視覚的な配置
ヘルプモーダルが表示されている際、すべてのショートカット行は整合性のとれたグリッド形式で表示されなければならない（SHALL）。また、デスクトップ環境におけるウィンドウ幅の変更に対しても、レイアウトの崩れを防ぐためのレスポンシブな適応能力を備えなければならない（MUST）。

#### Scenario: デスクトップ環境での柔軟な配置
- **WHEN** ヘルプモーダルが表示されている
- **THEN** 各行の列（キー / ラベル / 説明文）は一定の位置から始まり、説明文の開始位置が縦に揃う
- **AND** ウィンドウ幅がある程度確保されている場合、キーとラベルの列は視認性を保つための最小幅（例: 120px以上）を維持しつつ、余白に応じて柔軟に調整される

#### Scenario: 狭いウィンドウ幅でのレイアウト最適化
- **WHEN** ヘルプモーダルの表示領域が一定の幅（例: 600px）を下回る
- **THEN** ショートカットの各項目（キー、ラベル、説明）は、横方向の重なりを避けるために適切なスタック形式や、折り返しを許容するレイアウトに切り替わる
- **AND** ユーザーが横スクロールをすることなく、すべての情報を閲覧できる

#### Scenario: バージョン情報の表示
- **WHEN** ヘルプモーダルが表示されている
- **THEN** モーダル内の最下部に現在のバージョン（例: `v1.4.0`）が表示される
- **AND** 開発版（unstable ブランチ由来）の場合、開発版であることが明示される
- **AND** バージョン情報の直上には視覚的な区切り線が表示される
