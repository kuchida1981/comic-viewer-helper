## Context

現在のヘルプ画面では、要素が以下の順序で表示されています：
1. ショートカットリスト
2. バージョン番号（境界線あり）
3. 同期設定（境界線あり）

この配置は一般的ではなく、バージョン番号が設定項目に挟まれる形になっており、視覚的な一貫性が欠けています。

## Goals / Non-Goals

**Goals:**
- ヘルプ画面の要素を論理的な順序（ショートカット -> 同期設定 -> バージョン番号）に並べ替える。
- 各セクション間の視覚的な区切りを整理し、一貫性を持たせる。
- バージョン番号をフッターとして最下部に固定する。

**Non-Goals:**
- 同期設定の機能自体の変更。
- 新しいショートカットの追加。

## Decisions

### 1. 要素のレンダリング順序の変更
`src/ui/components/HelpModal.ts` において、`contentChildren` 配列への要素追加順序を変更します。
- **Rationale**: `HelpModal` は `extraContent`（同期設定など）を受け取る汎用的な構造になっています。`versionTag` を常に最後に追加するように変更することで、どのような追加コンテンツがあってもバージョン番号が最下部に配置されることを保証します。

### 2. ショートカットリストの境界線調整
`src/ui/styles.ts` において、`.comic-helper-shortcut-row:last-child` の `border-bottom` を `none` に設定します。
- **Rationale**: 後続のセクション（同期設定やバージョン番号）が `border-top` を持っているため、最後の行に `border-bottom` があると二重線に見えてしまいます。CSSで制御することで、JavaScript側でインデックスを意識することなくクリーンな見た目を維持できます。

### 3. 同期設定セクションのマージン調整
`src/ui/components/SyncSettings.ts` の `titleEl` に `marginTop: '15px'` を追加します。
- **Rationale**: バージョン番号のタグ (`versionTag`) が既に `marginTop: '15px'` を持っているため、同期設定セクションにも同じマージンを適用することで、セクション間の余白に一貫性を持たせます。

## Risks / Trade-offs

- **[Risk]** 同期設定以外の `extraContent` が渡された場合に、そのコンテンツもバージョン番号の上に配置される。
- **[Mitigation]** 現状 `extraContent` は同期設定にのみ使用されており、意味論的にも「追加の設定項目」などはバージョン番号（メタ情報）より上にあるべきなので、この挙動は望ましいものです。
