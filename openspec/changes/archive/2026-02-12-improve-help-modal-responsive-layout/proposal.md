## Why

現在のヘルプモーダルは、ショートカット一覧の列幅が固定（180px, 140px）されており、デスクトップ環境であってもウィンドウ幅を縮小した際や、サイドバー等の狭い領域で表示された場合に、レイアウトが崩れたり横スクロールが発生したりする課題があります。メディアクエリと柔軟なグリッドレイアウトを導入することで、さまざまな画面幅において堅牢なレスポンシブ性を確保します。

## What Changes

- `src/ui/styles.ts` における `.comic-helper-shortcut-row` の `grid-template-columns` を、固定幅から `minmax` 等を用いた柔軟な定義に変更します。
- メディアクエリを追加し、ウィンドウ幅が一定以下（例: 600px未満）になった場合に、各要素をスタック（1列表示）またはより適切なレイアウトに切り替えるようにします。
- モーダル自体の最大幅やパディングも、必要に応じて調整し、視認性を向上させます。

## Capabilities

### New Capabilities
- なし

### Modified Capabilities
- `help-display`: ウィンドウ幅が狭い場合でもレイアウトが維持される、あるいは適切に最適化されるというレスポンシブ要件を追記します。

## Impact

- `src/ui/styles.ts`: CSS グリッド定義およびメディアクエリの追加
- ヘルプモーダルの UI: 狭いウィンドウ幅での表示が改善される
