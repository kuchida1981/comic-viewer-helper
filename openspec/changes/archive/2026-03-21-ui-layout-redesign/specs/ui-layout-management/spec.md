## ADDED Requirements

### Requirement: Multi-row Control Panel Layout
システムは、メインUI（コントロールパネル）を論理的なグループに基づいた複数行（標準で2行）のレイアウトで構成しなければならない（SHALL）。これにより、機能増加に伴う横方向への過度な伸長を抑制し、コンパクトなフットプリントを維持する。

#### Scenario: 2行構成の表示
- **WHEN** コントロールパネルが表示される
- **THEN** パネル内部が「上段（メイン操作）」と「下段（設定・ツール）」の2つの行に分かれて配置される
- **AND** 上段には電源、ページカウンター、および主要なナビゲーションボタンが含まれる
- **AND** 下段には見開き、オートプレイの設定、および各種ツールボタンが含まれる

### Requirement: Responsive Control Grouping
コントロールパネルは、画面幅が不足する場合に、各行の要素が適切に折り返されるレスポンシブな挙動を提供しなければならない（SHALL）。

#### Scenario: 狭い画面幅での折り返し
- **WHEN** ウィンドウサイズが縮小され、コントロールパネルの1行の幅が収まりきらなくなったとき
- **THEN** 各行の要素が `flex-wrap` により自動的に次の行へ送り出され、すべてのボタンがアクセス可能な状態で保持される
