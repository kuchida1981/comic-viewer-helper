# Proposal

## Why

タグクラウドは「どのタグが多いか」を示すが、「どのタグ同士が結びついているか」は分からない。お気に入りのタグの関係を、動きのあるグラフとして眺められるようにし、楽しさと発見を提供する（#292）。

## What Changes

- お気に入りタブのビュー切替に、一覧・タグクラウドと並ぶ「グラフ」ビューを追加する
- タグをノード（大きさは出現件数、色は種類）、同じ作品に付くタグ同士（共起）を線として表示する
- 物理シミュレーションによる配置、ノードのドラッグ、ホバーでの隣接強調、ズームとパンを提供する
- 毛玉化を避けるため、ノードは件数上位 50 件、線は共起 2 件以上かつ関連の強いものに絞る
- ノードのクリックで、そのタグで絞り込んだ一覧ビューへ切り替える
- グラフビューにもタグの種類フィルタを提供する（タグクラウドの選択状態とは独立）

ズームと表示位置は「表示を元に戻す」ボタンで初期状態に戻せる。

対象外: ノード数のスライダー（#294）、作品ノード、タブレット・スマートフォンでの利用（タッチ操作）、タグクラウドビューの変更。

## Capabilities

### New Capabilities
- `favorites-tag-graph`: お気に入りタグの共起関係をグラフとして表示し、操作する

### Modified Capabilities

なし

## Impact

- `src/logic.ts`: グラフ構築と物理シミュレーションの純粋関数を追加
- `src/ui/components/`: グラフビューのコンポーネントを追加し、`FavoritesModal.ts` に組み込む
- `src/managers/UIManager.ts`: モーダルを閉じるときにアニメーションを停止する
- `src/ui/styles.ts`、`src/i18n.ts`: スタイルと文言を追加
- 実行時依存の追加はなし。保存データ形式の変更もなし
