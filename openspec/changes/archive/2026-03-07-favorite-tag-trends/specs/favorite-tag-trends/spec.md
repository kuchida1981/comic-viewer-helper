## ADDED Requirements

### Requirement: お気に入り作品のタグを集計しトレンドとして表示する
システムは、お気に入り一覧の表示時に、登録されている全作品のタグを動的に集計し、頻出順にトレンドとして表示しなければならない（SHALL）。

#### Scenario: お気に入り一覧でトレンドが表示される
- **WHEN** お気に入り一覧モーダルを開く
- **THEN** 保存されている全作品のタグが集計され、頻出上位のタグがトレンドセクションに表示される

### Requirement: トレンドタグをクリックして検索を実行する
ユーザーは、トレンドセクションに表示されたタグをクリックして、そのタグでの検索結果を表示できなければならない（SHALL）。

#### Scenario: トレンドタグをクリックして検索結果を表示する
- **WHEN** トレンドセクションのタグボタンをクリックする
- **THEN** お気に入り一覧モーダルが閉じ、検索モーダルが開いて、そのタグの検索結果が表示される
