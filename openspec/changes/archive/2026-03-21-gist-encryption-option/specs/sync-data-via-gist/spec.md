# Spec: Gist Sync Encryption Option

## ADDED Requirements
### Requirement: 同期データの暗号化オプション
同期設定において、暗号化なし（平文）かAES暗号化かを選択でき、AES暗号化時にはパスワードを設定できなければならない (MUST)。

#### Scenario: 平文からAES暗号化への切り替え
- **GIVEN** Gistに平文データが存在し、設定が「なし」になっている
- **WHEN** ユーザーが設定を「AES暗号化」に変更し、パスワードを入力して保存する
- **THEN** GistのデータがAES暗号化された形式で上書きされる

### Requirement: 暗号化データの復号と同期
システムは、Gist上の暗号化されたデータを正しいパスワードで復号し、ローカルデータとマージできなければならない (MUST)。

#### Scenario: 暗号化されたデータの同期
- **GIVEN** GistにパスワードAで暗号化されたデータが存在する
- **WHEN** ユーザーが正しいパスワードAを設定して同期を実行する
- **THEN** データが正常に復号され、同期が成功する

### Requirement: 復号失敗時のエラーハンドリング
システムは、パスワード不一致等で復号に失敗した場合、同期を中断しユーザーに適切なエラーメッセージを表示しなければならない (MUST)。

#### Scenario: パスワード間違いによるエラー
- **GIVEN** GistにパスワードAで暗号化されたデータが存在する
- **WHEN** ユーザーが間違ったパスワードBを設定して同期を実行する
- **THEN** 「復号に失敗しました」というエラーメッセージが表示され、データはマージされない
