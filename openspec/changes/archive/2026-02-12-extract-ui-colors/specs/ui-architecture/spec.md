## MODIFIED Requirements

### Requirement: CSS クラスによるスタイリングと色の定数化
UI のスタイリングは、JS 内のインラインスタイルではなく、外部または一括注入された CSS クラスによって定義されなければならない (MUST)。また、CSS 内で使用される色やサイズなどの基本値は、マジックナンバーを避け、定数として一元管理されなければならない (SHALL)。これにより、将来的なテーマ対応（ダークモード等）を容易にする。

#### Scenario: 定数によるスタイルの定義
- **WHEN** `src/ui/styles.ts` でスタイルを定義する時
- **THEN** 色指定にはハードコードされた文字列（例：`#333`）ではなく、共通のカラー定数（例：`COLORS.text.primary`）が使用される

#### Scenario: インラインスタイルでの定数利用
- **WHEN** 構造上または動的な理由でインラインスタイルが必要な箇所（例：`createElement` の `style` オプション）で色を指定する時
- **THEN** ハードコードされた値を使用せず、共通のカラー定数を参照する
