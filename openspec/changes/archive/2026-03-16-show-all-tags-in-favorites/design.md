## Context

現在のお気に入り一覧（Library）の「あなたの好み（Trends）」セクションでは、お気に入りに登録された作品からタグを集計して表示していますが、表示件数が上位10件に固定されています。タグが多数ある場合、10位以下のタグを選択して絞り込む手段がないため、全件表示への切り替え機能が必要です。

## Goals / Non-Goals

**Goals:**
- `calculateTrends` ロジックを拡張し、表示制限を解除可能にする。
- UI に「すべて表示」と「上位のみ」を切り替えるトグルボタンを追加する。
- 切り替え状態（`showAllTags`）をモーダル内で保持し、動的に表示を更新する。

**Non-Goals:**
- タグの検索機能の追加（今回は単純な全件表示に留める）。
- タグの並び順の変更機能（出現回数順を維持）。

## Decisions

### Decision 1: `calculateTrends` の拡張
- **選択**: `calculateTrends(favorites: RelatedWork[], limit: number = 10)` とし、`limit` に `0` または `undefined` が渡された場合は全件返す。
- **理由**: 既存の呼び出し箇所（UIやテスト）の挙動を変えずに、必要な場所でのみ制限を解除できる。

### Decision 2: UI トグルの配置
- **選択**: 「あなたの好み」ラベルの右側に、小さなリンク状のボタン（またはトグル）を配置する。
- **理由**: 既存のレイアウトを大きく崩さず、自然な位置で切り替えを提供できる。

### Decision 3: 状態管理
- **選択**: `createFavoritesModal` 内のクロージャ変数として `showAllTags: boolean` を保持する。
- **理由**: この状態はモーダルの表示中のみ有効であればよく、グローバルな `Store` に持たせる必要がない。

## Risks / Trade-offs

- **[Risk]** タグが極端に多い場合（数百個など）、全件表示時にモーダルが縦に非常に長くなる。
  - **Mitigation**: トレンドタグのコンテナに `max-height` を設定し、必要に応じてスクロール可能にする（CSS調整）。
- **[Risk]** モーダルの再描画によるチラつき。
  - **Mitigation**: `rerenderFavoritesPanel` では `replaceChild` を使用して特定のセクションのみを更新しており、大きな影響はないと考えられる。
