## ADDED Requirements

### Requirement: 同期設定のUIガイド
システムは、ユーザーが同期設定の各項目（GitHub PAT、Gist ID、暗号化モード、パスワード）を正しく理解し設定できるよう、各入力項目に対して取得方法や操作上の注意点を含む補足テキストを表示しなければならない (MUST)。また、設定画面の冒頭には機能の概要を示す導入テキストを表示しなければならない (MUST)。

#### Scenario: 同期設定画面の初期表示
- **WHEN** ユーザーがヘルプモーダル内の同期設定セクションを開いたとき
- **THEN** 画面上部に同期機能の概要（Gistを使用した他端末との同期）を説明するテキストが表示される
- **THEN** 各入力フィールド（PAT, Gist ID, 暗号化, パスワード）の近傍に、それぞれの役割や取得手順、操作時の注意を説明するテキストが表示される

#### Scenario: 暗号化設定変更のガイド表示
- **WHEN** ユーザーが暗号化モードを選択したり、パスワード入力フィールドを操作したりするとき
- **THEN** パスワードを忘れた際のリスクや、パスワード変更・暗号化解除の手順に関する具体的な説明が常に視認できる状態で表示される
