# internal-tag-navigation

## Modified Requirements

### Requirement: 検索結果ヘッダーからのタグ補完
検索結果画面のヘッダーに表示されているタグ名をクリックした際、そのタグ名をキーワードとして検索フォームに入力し、補完を行わなければならない（SHALL）。

#### Scenario: ヘッダーのタグ名クリックによる補完実行
- **WHEN** ユーザーが検索結果ヘッダーの「Genre: [タグ名]」等のタグ名部分をクリックした時
- **THEN** 検索フォームの入力値がその「タグ名」＋「半角スペース」に設定（上書き）される
