## Why

現状のプリコミットフック（Husky）は、Lint、型チェック、テスト、ビルドなどの検証がすべて成功した場合でも、膨大なログを出力します。これにより、ターミナル上でコミット自体の実行結果を確認するためにスクロールが必要になるなど、開発のテンポが損なわれています。
検証成功時は静かにし、失敗したときだけその原因（ログ）を表示するようにすることで、開発者が重要な情報に即座に集中できるようにします。

## What Changes

- `.husky/pre-commit` スクリプトの各検証コマンド（npm run lint, npm run test等）の出力を、成功時には表示しないように変更します。
- いずれかの検証コマンドが失敗（終了コードが非ゼロ）した場合には、そのコマンドの出力ログをすべて表示し、どのステップで失敗したかを明示します。

## Capabilities

### New Capabilities

なし

### Modified Capabilities

- `pre-commit-verification`: 検証結果の表示（フィードバック）方法に関する要件を調整し、成功時の静音化を許容・推奨するようにします。

## Impact

- `.husky/pre-commit`: 検証スクリプトのロジックが変更されます。
