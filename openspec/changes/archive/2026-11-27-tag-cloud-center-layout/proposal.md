# Proposal

## Why

タグクラウドビューのタグは文字列昇順に並んでおり、件数の多いタグがあちこちに散らばるため、好みの傾向をひと目で把握しにくい。件数の多いタグを中央に、少ないタグほど外側に配置し、傾向を俯瞰しやすくしたい（Issue #280）。

## What Changes

- タグクラウドビューの並びを、文字列昇順から「件数の多いタグが中央、少ないタグほど外側」へ変更する。
- 件数降順の1位を中央、2位を右、3位を左…と交互に外側へ配置する横一列の中央寄せ（ピラミッド型）とする。
- 件数が同じタグは、文字列昇順で順位を決める（並びを安定させるため）。
- 文字サイズの段階表示、上位200件の制限、種類フィルタは従来どおり動作する。
- 一覧ビューのトレンドセクションとお気に入り作品グリッドは変更しない。
- 配置の並べ替えは `logic.ts` の純関数として実装する。
- 円形・放射状の配置はスコープ外とする。

## Capabilities

### New Capabilities
なし。

### Modified Capabilities
- `favorites-tag-cloud`: タグクラウドビューの並びを「件数の多いタグが中央」とする要件を追加する。

## Impact

- `src/logic.ts`: 件数降順（同数は文字列昇順）で順位付けし、中央から外側へ並べ替える純関数を追加する。100% カバレッジを維持する。
- `src/ui/components/FavoritesModal.ts`: `createTagCloudSection` の文字列昇順ソートを、上記の関数に置き換える。
- `src/ui/components/FavoritesModal.test.ts`: 既存の並び順のテストを更新し、中央配置のテストを追加する。
- `src/ui/styles.ts`: 既存の `justify-content: center` のままで変更なしの見込み。
- `calculateTrends`、保存形式、`Store` は変更しない。
