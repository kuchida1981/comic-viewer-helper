## ADDED Requirements

### Requirement: Navigation by Keyboard
ユーザーはキーボード操作でページ（画像）を移動できる必要があります（SHALL）。

#### Scenario: Next page by 'j' key
- **WHEN** `j` キーを押下する
- **THEN** 次の画像がビューポートの最上部にスクロールされる

### Requirement: Navigation by Click
ユーザーは画面の左右をクリックすることでページを移動できる必要があります（SHALL）。

#### Scenario: Next page by left-side click
- **WHEN** 画面の左側（ビューポートの左半分）をクリックする
- **THEN** 次の画像へスクロールされる
