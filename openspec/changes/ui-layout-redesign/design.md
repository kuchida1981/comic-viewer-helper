## Context
現在のメインUIは、`src/ui/styles.ts` において `#comic-helper-ui` に対して `display: flex` と `white-space: nowrap` が適用されており、すべてのコンポーネントが横一列に並んでいます。機能追加により、このパネルが画面の横幅を大きく占有し、視認性や操作性を損なっています。

## Goals / Non-Goals

**Goals:**
- メインUIを2行構成に刷新し、横幅を約50%程度に短縮する。
- ナビゲーション（移動）と設定（見開き・オートプレイ等）を論理的に分離する。
- アイコン化（作品情報 ℹ️, ヘルプ ❓ 等）により、視認性を高めつつスペースを節約する。
- 画面幅が狭い場合に、要素が適切に折り返されるようにする。

**Non-Goals:**
- UI全体のカラーパレットやテーマの大幅な変更。
- 既存のドラッグ移動機能の廃止（維持する）。
- 新機能（例：ブックマーク管理）の追加。

## Decisions

### 1. 複数行（Row）構造の導入
**Decision:** `#comic-helper-ui` を `flex-direction: column` に変更し、内部に `.comic-helper-row` というラッパーを導入して各行を管理します。
**Rationale:** 既存の `flex` レイアウトを活かしつつ、行単位での管理を容易にするため。

### 2. コンポーネントの再グループ化
**Decision:**
- **Row 1 (Top)**: 電源ボタン、ページカウンター、ナビゲーションボタン群（<<, <, 🎲, >, >>）
- **Row 2 (Bottom)**: 見開き設定、オートプレイ設定、検索(🔍)、ライブラリ(📚)、作品情報(ℹ️)、ヘルプ(❓)、お気に入り(❤️)
**Rationale:** 頻繁に使う「移動」系を上段に、設定や補助ツールを下段に分けることで、ユーザーの迷いを減らす。

### 3. NavigationButtons インターフェースの拡張
**Decision:** `createNavigationButtons` が単一の配列ではなく、`navElements` と `utilElements` の2つのグループを返すように変更します。
**Rationale:** `UIManager` 側で、どのボタンをどの行に配置するかを制御しやすくするため。

### 4. テキストラベルのアイコン化
**Decision:** `Info` というテキストを `ℹ️` アイコンに、`?` を `❓` に変更します。
**Rationale:** 他のツールボタン（🔍, 🎲 等）との統一感を持たせ、横幅を圧縮するため。

## Risks / Trade-offs

- [Risk] 要素を2行にすることで、縦方向の占有面積が増える。 → [Mitigation] 行間の gap を最小限（4px等）にし、各行の padding を調整して全体の高さを抑える。
- [Risk] ボタンの並び順が変わることで、既存ユーザーが戸惑う。 → [Mitigation] 基本的な「進む・戻る」の順序や相対的な位置関係は維持する。
- [Risk] ドラッグ移動時の「画面端での挙動」が複雑になる。 → [Mitigation] `Draggable` クラスのクランプ処理が正しく動作することを確認し、必要に応じて修正する。
