## MODIFIED Requirements

### Requirement: Metadata Access GUI
ユーザーは、GUI上のボタン（作品情報アイコン ℹ️）を通じてメタデータ閲覧モーダルを開くことができなければならない（SHALL）。

#### Scenario: モーダルを開く
- **WHEN** ユーザーがGUI上の作品情報アイコンをクリックする
- **THEN** メタデータ閲覧モーダルが表示される
- **AND** モーダルが表示されている間、背景は半透明のオーバーレイで覆われる

### Requirement: Metadata Modal Content
メタデータ閲覧モーダルは、抽出された情報を分かりやすく表示しなければならない（SHALL）。セクションのタイトル（例: "Tags", "Related Works"）は、現在の言語設定に応じた翻訳テキストで表示される。
- **タイトル**: 作品のメインタイトルをモーダルの上部に強調表示する。
- **タグ**: クリック可能なチップ形式で表示し、クリックすると外部サイトへ遷移する代わりに内部検索モーダルを開き、そのタグでの検索結果を表示する。タグは種別（artist, character 等）に応じて色分けして表示する。
- **関連作品**: サムネイルとタイトルを表示し、クリックすると別タブでリンク先を開く。

#### Scenario: タグの内部検索起動
- **WHEN** ユーザーがメタデータモーダル内のタグチップをクリックした時
- **THEN** ブラウザの遷移（デフォルト動作）がキャンセルされる
- **AND** 内部検索機能が、そのタグのURLを対象として呼び出される

#### Scenario: 翻訳されたセクションラベルの表示
- **WHEN** 日本語環境で作品情報モーダルが表示されている
- **THEN** 「タグ」や「関連作品」といった日本語のセクションタイトルが表示される

#### Scenario: タグの色分け表示
- **WHEN** ユーザーがメタデータモーダルを開く
- **THEN** 各タグはその種別に応じた背景色で表示される
- **AND** 種別が不明なタグはデフォルトのグレー背景で表示される
