## ADDED Requirements

### Requirement: ユーザー機能のベネフィット指向の説明
システムは、README において、主要なユーザー機能を単なる機能名ではなく、それによって得られる利便性（ベネフィット）と共に説明しなければならない (MUST)。
例えば、「レジューム機能」ではなく「続きから読む（安心感）」といったニュアンスを込めた表現を採用する。

#### Scenario: 機能説明のトーン確認
- **WHEN** ユーザーが README の機能紹介セクションを読んだとき
- **THEN** 各機能がユーザーのどのような問題を解決するか（例：中断した場所から再開できる）についての記述が含まれていること

### Requirement: 操作方法（キーボードショートカット等）の詳細提示
システムは、README において、アプリケーションの主要な操作方法、特にキーボードショートカットの一覧を詳細に提示しなければならない (MUST)。
これにより、ユーザーがスクリプトの機能を最大限に活用できるようにする。

#### Scenario: ショートカット一覧の確認
- **WHEN** ユーザーが README の「使い方」セクションを読んだとき
- **THEN** 「次の画像へ」「前の画像へ」「見開き切替」などのキーアサインが一覧表形式で記載されていること
