# Proposal

## Why

お気に入り一覧モーダルのタグクラウド（トレンドセクション）には、artist・genre・character など種類の異なるタグが混在して表示される。タグ数が増えると、関心のある種類（例: genre だけ）のタグを見つけにくい。タグクラウドを種類で絞り込めるようにしたい（Issue #279）。

## What Changes

- タグクラウドの上部に、タグの種類ごとのトグルチップ（種類フィルタ）を追加する。デフォルトはすべて有効で、チップをクリックするとその種類のタグがタグクラウドから除外される。再度クリックすると戻る。
- 種類チップには既存のタイプカラー（`comic-helper-tag-chip--{type}`）を流用し、凡例を兼ねる。無効な種類は薄く表示する。
- 種類チップは、お気に入りに実際に存在する種類のみ表示する。`type` が `null` のタグは「その他」として扱う。
- 除外はタグクラウドの表示にのみ作用する。下のお気に入り作品グリッドの絞り込みには影響しない。
- 選択中のタグは、その種類が除外されても表示を維持する。
- 除外状態はモーダル内のローカル状態とし、モーダルを閉じるとリセットする（永続化しない）。
- 除外判定は `logic.ts` の純関数（`calculateTrends` の拡張）として実装する。
- 「上位10件 / すべて表示」の件数制限は、除外後のタグに対して適用する。

## Capabilities

### New Capabilities
なし。

### Modified Capabilities
- `favorite-tag-trends`: タグクラウドを種類で絞り込む要件を追加する。

## Impact

- `src/logic.ts`: `calculateTrends` に除外種類の引数を追加し、種類一覧を求める純関数を追加する。100% カバレッジを維持する。
- `src/ui/components/FavoritesModal.ts`: 種類フィルタのチップ描画と除外状態の管理を追加する。
- `src/ui/styles.ts`: 種類チップ（無効状態を含む）のスタイルを追加する。
- `src/i18n.ts`: 「その他」ラベルなどの文言を追加する。
- 関連テスト（`logic.test.ts`、`FavoritesModal.test.ts`）を追加する。
- 保存形式・`Store`・`SyncManager` は変更しない。
