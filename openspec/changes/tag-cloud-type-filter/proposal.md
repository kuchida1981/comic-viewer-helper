# Proposal

## Why

お気に入り一覧モーダルのタグクラウドビューには、artist・genre・character など種類の異なるタグが混在して表示される。タグ数が増えると、関心のある種類（例: genre だけ）のタグを見つけにくい。タグクラウドビューを種類で絞り込めるようにしたい（Issue #279）。

## What Changes

- タグクラウドビューの上部に、タグの種類ごとのトグルチップ（種類フィルタ）を追加する。デフォルトはすべて有効で、チップをクリックするとその種類のタグがタグクラウドから除外される。再度クリックすると戻る。
- 種類チップには既存のタイプカラー（`comic-helper-tag-chip--{type}`）を流用し、凡例を兼ねる。無効な種類は薄く表示する。
- 種類チップは、お気に入りに実際に存在する種類のみ表示する。`type` が `null` のタグは「その他」として扱う。
- 対象はタグクラウドビューのみとする。一覧ビューのトレンドセクションと、お気に入り作品グリッドは変更しない。
- 除外は上位200件の絞り込みの前に行う。除外された種類のタグが件数枠を消費しない。
- 除外状態はモーダル内のローカル状態とし、モーダルを閉じるとリセットする（永続化しない）。
- 除外判定は `logic.ts` の純関数として実装する。

## Capabilities

### New Capabilities
なし。

### Modified Capabilities
- `favorites-tag-cloud`: タグクラウドビューを種類で絞り込む要件を追加する。

## Impact

- `src/logic.ts`: `calculateTrends` に除外種類の引数を追加し、種類一覧を求める純関数を追加する。100% カバレッジを維持する。
- `src/ui/components/FavoritesModal.ts`: `createTagCloudSection` に種類フィルタのチップ描画と除外状態の管理を追加する。
- `src/ui/styles.ts`: 種類チップ（無効状態を含む）のスタイルを追加する。
- `src/i18n.ts`: 「その他」ラベルを追加する。
- 関連テスト（`logic.test.ts`、`FavoritesModal.test.ts`）を追加する。
- 保存形式・`Store`・`SyncManager` は変更しない。
