## ADDED Requirements

### Requirement: タグクラウドビューをタグの種類で絞り込む
システムは、お気に入り一覧のタグクラウドビューに、タグの種類（artist、genre など）ごとの表示切り替えを提供しなければならない（SHALL）。デフォルトではすべての種類が有効でなければならない（SHALL）。種類を無効にした場合、その種類のタグをタグクラウドから除外しなければならない（SHALL）。種類の切り替えは、タグクラウドビューの表示にのみ作用し、一覧ビューのトレンドセクションおよびお気に入り作品グリッドの内容を変更してはならない（SHALL NOT）。

#### Scenario: デフォルトではすべての種類が有効
- **WHEN** タグクラウドビューを表示する
- **THEN** お気に入りに存在するすべての種類が有効状態の種類チップとして表示され、全種類のタグがタグクラウドに表示される

#### Scenario: 種類を無効にするとその種類のタグが消える
- **WHEN** 種類チップ「genre」をクリックして無効にする
- **THEN** `type` が `genre` のタグがタグクラウドから除外され、他の種類のタグは表示されたままになる

#### Scenario: 無効にした種類を再度有効にすると戻る
- **WHEN** 無効にした種類チップを再度クリックする
- **THEN** その種類のタグがタグクラウドに再び表示される

#### Scenario: 無効な種類のチップも表示され続ける
- **WHEN** 種類を無効にしてタグクラウドからその種類のタグが消える
- **THEN** その種類のチップは薄い無効状態で表示され続け、再度有効にできる

#### Scenario: すべての種類を無効にしてもチップは操作できる
- **WHEN** すべての種類チップを無効にする
- **THEN** タグクラウドにはタグが表示されず、種類チップは表示されたままで再度有効にできる

#### Scenario: お気に入りに存在する種類のみチップを表示する
- **WHEN** お気に入りに `artist` と `genre` のタグしか存在しない
- **THEN** 種類チップは「artist」と「genre」のみ表示される

#### Scenario: 種類が1つ以下のときはチップを表示しない
- **WHEN** お気に入りのタグの種類が1つ以下である
- **THEN** 種類チップは表示されない

#### Scenario: 種類のないタグは「その他」として扱われる
- **WHEN** お気に入りに `type` が `null` のタグが存在する
- **THEN** 「その他」の種類チップが表示され、そのチップの切り替えで `type` が `null` のタグの表示・非表示が切り替わる

#### Scenario: 一覧ビューは種類フィルタの影響を受けない
- **WHEN** タグクラウドビューで種類を無効にして一覧ビューに切り替える
- **THEN** トレンドセクションとお気に入り作品グリッドの表示は、種類フィルタの影響を受けない

### Requirement: 種類フィルタは上位200件の絞り込み前に適用する
システムは、タグクラウドビューの上位200件の件数制限を、種類フィルタで除外した後のタグに対して適用しなければならない（SHALL）。

#### Scenario: 除外された種類のタグが件数枠を消費しない
- **WHEN** 種類を無効にした結果、残りのタグが200件を超えている
- **THEN** 残ったタグのうち出現件数の多い200件が表示され、除外された種類のタグが件数枠を消費しない

#### Scenario: 除外後に文字サイズの段階は表示中のタグで決まる
- **WHEN** 種類を無効にする
- **THEN** 文字サイズの段階は、表示中のタグの最少件数と最多件数を基準に計算される

### Requirement: 種類フィルタの状態はモーダルを閉じるとリセットする
システムは、種類フィルタの状態を永続化してはならず（SHALL NOT）、お気に入り一覧モーダルを閉じて開き直した場合はすべての種類を有効に戻さなければならない（SHALL）。

#### Scenario: モーダルを開き直すと全種類が有効に戻る
- **WHEN** 種類を無効にした後、モーダルを閉じて再度開く
- **THEN** すべての種類が有効状態で表示される
