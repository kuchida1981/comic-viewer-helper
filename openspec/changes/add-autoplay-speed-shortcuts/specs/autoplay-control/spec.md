## MODIFIED Requirements

### Requirement: Autoplay Interval Configuration UI
GUIパネルには、オートプレイの有効/無効を切り替えるチェックボックスと、待機秒数（1〜99秒）を指定する数値入力フィールドが含まれていなければならない（SHALL）。また、ユーザーはキーボードショートカット（`[` および `]`）を使用して、待機秒数を 1秒 単位で増減できなければならない（SHALL）。

#### Scenario: 待機時間の変更（UI経由）
- **WHEN** ユーザーがGUIの数値入力フィールドで待機時間を変更する
- **THEN** `Store` の `autoplayInterval` が更新される
- **AND** オートプレイが有効な場合は、新しい待機時間に基づいてタイマーが再設定される

#### Scenario: 待機時間の減少（ショートカット `]`）
- **WHEN** ユーザーが `]` キーを押下する
- **AND** 現在の待機時間が 1秒 より大きい
- **THEN** `Store` の `autoplayInterval` が 1秒 減少する（速度が上がる）
- **AND** オートプレイが有効な場合は、新しい待機時間に基づいてタイマーが再設定される

#### Scenario: 待機時間の増加（ショートカット `[`）
- **WHEN** ユーザーが `[` キーを押下する
- **AND** 現在の待機時間が 99秒 未満である
- **THEN** `Store` の `autoplayInterval` が 1秒 増加する（速度が下がる）
- **AND** オートプレイが有効な場合は、新しい待機時間に基づいてタイマーが再設定される
