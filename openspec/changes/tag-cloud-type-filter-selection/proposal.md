## Why

現在のタグクラウドビューのタグ種別フィルタは、初期状態で全種別が選択されている状態で任意の種別をクリックすると「その種別だけが除外される」という減算方式になっている。特定の種別（例：`artist` のみ、あるいは `artist` と `genre` のみ）に絞り込んで傾向を見たい場合、他のすべての種別を1つずつクリックして除外する必要があり操作が煩雑である。直感的な「選んだ種別だけを残し、必要に応じて他を追加選択し、ワンクリックで全選択に戻せる」操作へ見直したい。

## What Changes

- タグクラウドビューを開いたときの初期状態は従来どおり「すべてのタグ種類が選択状態」とする。
- 全選択状態で任意のタグ種類を選択すると、その種類だけが選択状態になり、それ以外の種類が除外されるように変更する。
- 1つ以上の種類が除外されている状態で、除外されている種類を選択すると、その種類も選択状態に追加される（表示対象が増える）。
- 1つ以上の種類が除外されている状態で、すでに選択されている種類を選択すると、その種類が除外される。ただし、選択されている最後の1種類は除外できない（最低1種類は選択状態が維持される）。
- 選択状態を解除して全選択に戻す「リセット（Reset）」ボタンを種類チップの行に追加する。全選択状態のときは非活性（disabled）とする。
- 上記以外の挙動（上位200件の制限前のフィルタ適用、中央配置レイアウト、一覧ビューへの非影響、モーダルを閉じたときのリセット、お気に入り更新時の状態維持、種類が1つ以下のときの非表示）は変更しない。
