# Proposal

## Why

お気に入り一覧のトレンドセクションは上位10件(切替で全件)を同じ大きさのボタンで並べるだけで、タグ間の頻度差や全体の傾向を俯瞰しにくい。出現頻度に応じて文字サイズを変えるタグクラウドで表示すれば、自分の好みの傾向を直感的に把握でき、気になったタグからすぐにお気に入りを絞り込める。(Issue #277)

## What Changes

- お気に入り一覧モーダルのお気に入りタブに、「一覧」と「タグクラウド」を切り替える別ビューを追加する(既存のトレンド表示は置き換えない)
- タグクラウドビューは、お気に入り全作品の全タグを対象に、出現件数に応じた段階的な文字サイズで表示する(件数の上限は設けない)
- タグクラウドのタグをクリックすると、そのタグで絞り込まれた状態のお気に入り一覧ビューに切り替わる
- 出現件数から文字サイズ段階を求める処理を `src/logic.ts` の純粋関数として追加する
- 切替ボタンなどのラベルを i18n(日本語/英語)に追加する
- 保存データ(`state.favorites` など)の形式は変更しない

## Capabilities

### New Capabilities
- `favorites-tag-cloud`: お気に入り作品の全タグを頻度に応じた文字サイズのタグクラウドとして表示し、クリックで絞り込み済みお気に入り一覧へ遷移する

### Modified Capabilities
<!-- 既存 spec の要件変更はなし。既存のトレンド表示(favorite-tag-trends)・一覧表示(favorites-list)の挙動は維持する -->

## Impact

- `src/logic.ts` / `src/logic.test.ts`: タグクラウド用のサイズ段階計算関数を追加(カバレッジ100%維持)
- `src/ui/components/FavoritesModal.ts`(および関連テスト): ビュー切替UI、タグクラウド描画、クリック時の絞り込み連携
- `src/ui/styles.ts`: タグクラウド用スタイル
- `src/i18n.ts`: 新規文言(日本語/英語)
- 依存ライブラリの追加なし、データ形式の変更なし
